- [ ] CONSTRAINT: Marker SVG inner icons must use `stroke="white"` not `fill="white"` — The `.replace(/stroke="white"/g, ...)` only changes stroke attributes to the severity color. `fill="white"` stays white against the white circle background, making the icon invisible.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| SVG fill-on-white invisibility | Marker status icons using `fill="white"` / `fill="white"` are invisible against the `opacity="0.95"` white center circle because the stroke color replacement doesn't apply to fill attributes | blocking | All `STATUS_INNER_ICONS` SVG paths must use `stroke="white"` with `fill="none"`. Never use `fill="white"`. Verifiable: grep for `fill="white"` in `EmergencyMap.tsx`. |
| Severity color distinguishability | `#DC2626` (red), `#F59E0B` (amber), `#FBBF24` (yellow) are too similar on a map — users couldn't distinguish High from Medium | advisory | Use distinct spectral bands: red → orange → teal → violet, not red → amber → yellow. |
